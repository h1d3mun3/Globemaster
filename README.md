# KanaCommand

macOS用のメニューバー常駐アプリです。Commandキーの単体押しで入力ソースを切り替えます。

- **左⌘** を単体で押して離す → **英数**
- **右⌘** を単体で押して離す → **かな**

⌘+C などのショートカットは通常通り動作します。

## 必要環境

- macOS 26.2以降
- アクセシビリティ権限の許可

## インストール

1. `KanaCommand.app` を `/Applications` に配置
2. アプリを起動
3. **システム設定 > プライバシーとセキュリティ > アクセシビリティ** で KanaCommand を許可

## ビルド

1. Xcode でプロジェクトを開く
2. `⌘R` でビルド＆実行

## 使い方

- 起動するとメニューバーに ⌘ アイコンが表示され、自動的にキー変換が有効になります
- メニューから「終了」を選択するとアプリが終了し、キー変換も無効になります
